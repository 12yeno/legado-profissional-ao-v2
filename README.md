# Legado Profissional AO

Protótipo visual da plataforma de carreira, currículos, perfis, formação e serviços profissionais.

## Publicação
O site é estático e pode ser usado para prototipagem no GitHub Pages. Para produção comercial, contas, base de dados, upload privado de documentos, chat e pagamentos devem ser implementados num backend/serviço apropriado.

## Importante
Os certificados exibidos são apenas modelos visuais marcados como “EXEMPLO • NÃO OFICIAL”. A plataforma não deve fabricar certificados académicos.
