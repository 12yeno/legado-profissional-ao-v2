Como funciona

O fluxo que vamos transformar num sistema real.

1. Instituição

Cria conta e passa pela validação.

2. Alunos

Utilizadores autorizados registam os alunos.

3. Emissão

A instituição emite o documento com código único.

4. Verificação

O código ou QR permite consultar a autenticidade.

🔎 Verificar documento

Na versão final, o código será consultado numa base de dados segura.
